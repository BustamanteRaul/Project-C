# MySharpVenture · documentación 1.0

- **MySharpVenture-SDD-v1.0.md:** documento principal en Markdown.
- **MySharpVenture-SDD-v1.0.html:** documento completo con los 16 diagramas incorporados. Abrilo en un navegador; funciona sin conexión y no necesita otros archivos para mostrar las imágenes.
- **diagramas/**: PNG para visualización, SVG para ampliación y edición, y fuentes Mermaid. Los diagramas 13, 14 y 15 corresponden a casos de uso.
- **Diagramas-Mermaid-v1.0.md:** anexo con las fuentes de todos los diagramas.

Para ver los gráficos en Markdown, descomprimí el ZIP completo y mantené la carpeta `diagramas` junto al documento. Si abrís únicamente el Markdown separado de esa carpeta, sus imágenes no estarán disponibles. La versión HTML evita esa dependencia.

Las relaciones del modelo relacional se expresan con cardinalidades numéricas en las imágenes y con pata de cuervo en Mermaid. Los casos de uso utilizan Mermaid 12; los PNG y SVG no requieren soporte para esa sintaxis. Las fuentes Graphviz `.dot` de los diagramas de estados, flujo, clases y base de datos también se incluyen.

La entrega del MVP está prevista para el miércoles 2 de diciembre de 2026. El documento distingue el MVP, el diseño completo y las ampliaciones fuera de alcance. Las pruebas de aceptación del juego forman parte del plan de desarrollo.
